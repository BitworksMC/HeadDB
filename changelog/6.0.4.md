# HeadDB 6.0.4 Changelog

## Fixed

- Modern Paper servers now use Paper's supported `PlayerTextures` path for
  MineSkin-published Mojang textures.
- HeadDB-hosted texture URLs remain supported only as a compatibility fallback
  for an old local catalog cache while it advances to the current API revision.

## Catalog

- The plugin continues to restore `plugins/HeadDB/catalog-cache.json` at startup
  and checks the HeadDB revision feed at the configured interval.
